# Romeo

Landing page for Romeo: ask anything, get a short animated story.

Plain static site (HTML, CSS, JS), no build step.

- `index.html` – the landing page; `manifesto.html` – the manifesto
- `motion.js` – scroll choreography (uses Lenis from jsDelivr); `voice-demo.js` – the replayed prototype
- `tools/serve.py` – local preview server with video range support: `python3 tools/serve.py 8790 .`
- `tools/make-clouds.py` – regenerates the painted cloud PNGs

3D icons by [Thiings](https://www.thiings.co) (free for non-commercial use with attribution).
